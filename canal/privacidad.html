Política de privacidad

Última actualización: 4 de noviembre de 2026

Inicio Condiciones del servicio

Quiénes somos

HoyvinPlay es un canal personal de vídeos cortos de videojuegos, llevado por una sola persona. No es una empresa. El contacto para cualquier asunto relacionado con esta política es hoyvinplay@gmail.com.

Qué cubre esta política

Cubre dos cosas:

  • Esta página web.
  • Las herramientas propias que el canal usa para publicar sus vídeos en sus propias cuentas a través de las API oficiales de YouTube, TikTok e Instagram. Esas herramientas no se ofrecen a terceros: solo las usa el propietario del canal, y solo sobre las cuentas del canal.

Esta web

Es una web estática. No tiene formularios, ni registro, ni comentarios, ni publicidad, ni cookies propias, ni herramientas de analítica. No se recoge ningún dato personal a través de ella.

Está alojada en GitHub Pages. Como cualquier servidor web, GitHub registra datos técnicos de las visitas, como la dirección IP, para poder servir las páginas y protegerse frente a abusos. Eso lo hace GitHub, no nosotros, y se rige por la declaración de privacidad de GitHub.

Las herramientas de publicación

El canal usa programas propios, que se ejecutan en el ordenador personal del propietario, para subir y programar sus vídeos sin tener que hacerlo a mano en cada plataforma.

Datos de usuario de Google y de YouTube

La aplicación HoyvinPlay subidas pide autorización mediante OAuth 2.0 sobre la cuenta de Google del propio canal, con dos permisos:

  • youtube.upload, para subir y programar vídeos en el canal.
  • youtube.readonly, para leer datos del propio canal, como el listado de vídeos y las estadísticas públicas.

Sobre esos datos:

  • Solo se accede a la cuenta del propio canal. No se accede a cuentas de otras personas, ni se pide a nadie que autorice nada.
  • El testigo de acceso (token) se guarda únicamente en el disco del ordenador del propietario, en un fichero local. No se sube a ningún servidor, no se comparte con nadie y no se usa para ninguna otra cosa.
  • No se venden, alquilan ni ceden datos a terceros. No se usan para publicidad ni para elaborar perfiles. No se transfieren a modelos de inteligencia artificial.
  • Los únicos datos que se leen son los del propio canal, y se usan solo para publicar vídeos y para llevar el seguimiento interno de cómo funcionan.

El uso de la información recibida de las API de Google se ajusta a la Política de Datos de Usuario de los Servicios de las API de Google, incluidos los requisitos de uso limitado.

La autorización se puede retirar en cualquier momento desde la página de permisos de la cuenta de Google. Al retirarla, el programa deja de funcionar de inmediato.

TikTok e Instagram

Si en el futuro se usan las API de TikTok o de Instagram, será exactamente en las mismas condiciones: únicamente sobre las cuentas del propio canal, con las credenciales guardadas en local, sin acceso a cuentas de terceros y sin cesión de datos a nadie.

Conservación y borrado

Las credenciales se conservan mientras el canal siga publicando, y se borran del disco cuando dejan de hacer falta o cuando se retira la autorización. Como no se recogen datos de otras personas, no hay nada de terceros que conservar ni que borrar. Aun así, si crees que tenemos algún dato tuyo y quieres que lo eliminemos, escribe a hoyvinplay@gmail.com y se hará.

Menores

Ni esta web ni las herramientas están dirigidas a menores de 14 años, y no recogen datos de ellos.

Cambios

Si esta política cambia, se actualizará esta página y la fecha de arriba.
